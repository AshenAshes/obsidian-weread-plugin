# 书架同步与本地读书笔记保护

## 同步范围

设置中的“同步范围”默认使用“书架中在读与已读的书”，需要有效的微信读书 API Key。

- 包含书架明确标记读完的书（`finishReading === 1`），不要求进度达到 100%。
- 包含未标记读完但阅读进度大于 0 的书。
- 不包含进度为 0 的未读完书籍，即使有少量阅读时长。
- 不自动删除移出书架或不再满足条件的本地文件。
- 最低划线数量不限制此模式；黑白名单仍然有效。
- 有声专辑和文章收藏入口不属于本次电子书同步范围。

也可以切换到“原笔记本列表”，继续使用原有的笔记本接口和划线数量筛选。无论使用哪种范围，本地读书笔记保护始终生效。

## 部分更新

同步根据四个一级标题划分范围，只替换元数据、高亮划线、本书评论。每个模块从一级标题开始，到下一个一级标题之前结束；本书评论延伸到文件末尾。首次创建时读书笔记为空，后续普通、强制、单本和定时同步均原样保留其标题和正文。第一个模块前的正文也保留。

```markdown
# 元数据
插件生成的书籍信息

# 高亮划线
插件生成的远端划线

# 读书笔记
在这里写自己的笔记，内部使用二级或更低级标题。

# 本书评论
插件生成的远端整本书评
```

不生成额外同步标记。请将本地内容放在读书笔记模块中；本书评论之后的正文属于评论模块，会随同步更新。

YAML 属性从文件最新正文读取并合并，自定义属性值保留；插件维护的身份、计数、ISBN、最近阅读日期及开启阅读信息保存时的阅读字段更新。YAML 排版和注释不保证保留。无有效日期时不生成 1970 年日期；取消读完后清除过期完成日期。

内置模板的划线不再生成块 ID 或 `weread://` 跳转链接，保留正文及模板原有的时间、想法展示。因此 Daily Note 或手动创建的划线块引用不再可用；书籍元数据中的 PC 地址保留。

高亮模块仍沿用所选模板的划线及附带想法展示；独立“读书笔记”模块不再导入远端章节想法。整本书评继续同步。

## 文件与自定义模板

文件和自定义模板必须按顺序包含元数据、高亮划线、读书笔记、本书评论四个一级标题，各出现一次，且无其他一级标题。标题缺失、重复、顺序异常或存在其他一级标题时，同步失败并保留原文件，不会回退到全篇覆盖。代码围栏内的标题不参与判断。

不提供此前试验版标记文件的迁移兼容。测试时请使用新生成的文件或符合上述四标题结构的文件。

## 失败处理与更新策略

每次同步重新获取候选书籍的进度、划线和书评，以覆盖“数量不变但内容变化”的情况。生成的文件内容相同则不写入。当前未使用未经验证的书架更新时间来跳过远端请求，因此首次及后续同步请求量会比原来增加。

书架/阅读状态获取失败时停止该轮；详情、划线、章节、书评获取失败时保留该本文件并记录失败。只有成功返回空数组才会清空相应远端模块。书评和笔记本概览检查分页是否完整。定时与手动同步使用同一互斥入口。

现有文件使用 Obsidian `Vault.process` 原子读取并合并，保留网络请求期间发生的本地编辑。最低 Obsidian 版本因此调整为 1.1.0。

## 开发验证与人工验收

```sh
npm install
npm test
npm run build
# 单个测试：
node --test --test-name-pattern="atomic" scripts/sync-regression.test.cjs
```

测试使用内存中的 Vault/API 替身，运行真实的目录筛选、解析、模板渲染、合并与保存代码，不访问账号或修改真实笔记。构建结果在 `dist/`，不会自动部署。

建议在测试库验收：

1. 选择书架在读与已读范围，确认零划线书籍也建立档案。
2. 在“读书笔记”中加入正文、图片引用和多级标题，连续普通同步与强制同步，确认内容保留。
3. 改变远端阅读进度或整本书评，确认三个同步模块及阅读属性更新。
4. 使用一份旧四模块笔记测试更新；删除一个模块标题后再次同步，确认提示失败且文件不变。
5. 保留自定义 YAML 属性，确认同步后值不变。


## 书架后台刷新

打开书架先显示当前插件运行期间缓存的远端结果，并重新匹配本地文件；没有缓存时先显示本地书籍。远端查询仍会在后台进行，成功后更新列表，失败则保留当前内容并显示提示。缓存仅保存在内存，重启插件后以本地书籍作为首次展示；切换账号或同步范围不会复用旧远端缓存。

后台刷新期间可以浏览、搜索和排序。仅有本地数据时暂不推断远端同步状态，也不按远端状态隐藏本地书籍。并发刷新共享同一次远端查询，页面关闭后的返回结果不会更新已关闭页面。此优化不改变详情页、统计页或定时同步行为。


## 导入书籍关联社区版本

在书籍详情页点击“关联社区版本”，输入书名搜索书城，点击搜索结果的“关联此版本”即可完成关联。搜索需要 API Key；结果可能只是部分版本，可修改关键词重搜。

关联保存在插件设置 `communityBooks` 中，以原书 ID 为键。热门划线和公开书评读取所选书城版本并标明来源；热门划线使用该版本的章节、位置和跳转链接。个人划线、想法、阅读进度仍读取原书，Markdown 同步逻辑不变，不把异版内容混入导入书章节或本地读书笔记。

此功能无法保证关联版本与微信读书 App 自动展示的社区版本一致，尤其是不同译本、修订版及删节版。社区请求失败时提示错误，不自动切换到其他版本。在详情页“更改社区版本”中可以解除关联。
